# Gate2 eSIM SDK — this page has moved

This page described the retired **1.0.x** eSIM SDK (`travel.gate2:esim:1.0.x` and the
`Gate2EsimScreen` composable). That API no longer exists in current releases.

For the current SDK use:

- **[ESIM_INTEGRATION_GUIDE.md](./ESIM_INTEGRATION_GUIDE.md)** — step-by-step eSIM integration
  (`travel.gate2:esim-<company>:<version>`, `Gate2Esim.start()`, payments, errors, checklist).
- **[README.md](./README.md)** — the whole SDK: installation, initialization, eSIM, Flights,
  Hotels, theming, troubleshooting and the changelog.
- **[README §15 Migrating from 1.0.x](./README.md#15-migrating-from-10x)** — if your app still
  uses the 1.0.x API.

`<company>` is the identifier Gate2 assigned to your build.
